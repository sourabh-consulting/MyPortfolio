A Slack-inspired chat application built with Next.js App Router and Socket.io. Features real-time messaging, channel management, file uploads, and message search.

## Key Features
- WebSocket-based real-time messaging
- End-to-end encryption for DMs
- File and image sharing with S3
- Full-text search with PostgreSQL FTS
