A white-label analytics SaaS built with Vue 3 and a Python/FastAPI backend. Multi-tenant with role-based access control and custom branding per organization.

## Key Features
- Drag-and-drop dashboard builder
- 20+ chart types powered by D3.js and Chart.js
- Real-time data streaming via WebSockets
- Multi-tenant with custom subdomain routing
