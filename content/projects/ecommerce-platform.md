Built with React on the frontend and Node.js/Express on the backend, this platform features a complete shopping experience with product catalog, cart management, Stripe Checkout integration, and order tracking.

## Key Features
- Real-time inventory with Redis pub/sub
- Stripe payment processing with webhooks
- Admin dashboard with sales analytics
- Abandoned cart email recovery flow
