A Python FastAPI backend paired with a React frontend. Integrates with OpenAI, Anthropic, and Google APIs to provide AI-powered content workflows.

## Key Features
- Multi-model AI orchestration (GPT-4, Claude)
- Automated SEO analysis and scoring
- Bulk content generation with custom templates
- Real-time streaming responses via SSE
